# JWT Guide

The maintained JWT documentation is [docs/security/jwt.md](docs/security/jwt.md).

Inna 2.0 requires PHP >=8.4 and firebase/php-jwt 7. Configure a strong JWT_SECRET; predictable default signing secrets are rejected. See [API authentication](docs/api/authentication.md) for starter endpoints and [upgrading](docs/advanced/upgrading.md) for changed token/response behavior.
